# FUTBOL IQ Fantasy

Bu repository, FUTBOL IQ markası altında web tabanlı özgün bir fantasy football ürününe dönüştürülmektedir.

## Ürün İlkeleri
- Sosyal Lig veya başka bir ürünün birebir kopyası değildir.
- Özgün marka, tasarım, oyun mekaniği ve puanlama sistemi hedeflenir.
- İlk sürüm responsive web uygulamasıdır; ileride iOS/Android istemcileri aynı backend'i kullanabilmelidir.
- Gerçek futbol verisi yoksa sahte canlı veri gösterilmez.
- Kullanıcı kritik hesaplamalarına client tarafında güvenilmez.

## V1 Odakları
1. Responsive application shell
2. Ana sayfa
3. Takım kurma ekranı
4. Oyuncu pazarı
5. Ligler ve sıralamalar için temel navigasyon
6. Fantasy domain tipleri ve game-rules mimarisi

Çalışma adı: `futbol-iq-fantasy`.
