# FUTBOL IQ Fantasy

**Strateji. Bilgi. Tutku.**

FUTBOL IQ Fantasy, gerçek futbol performanslarından beslenen özgün bir web tabanlı fantasy football ürünüdür.

## V1 hedefi
- Responsive web deneyimi
- Takım kurma ekranı
- Oyuncu pazarı
- Ligler ve sıralamalar
- Gerçek futbol verisine hazır provider mimarisi
- İleride mobil uygulama ile ortak backend

## Temel kurallar
- 15 kişilik kadro
- 2 kaleci, 5 defans, 5 orta saha, 3 forvet
- İlk 11 + 4 yedek
- Başlangıç bütçesi örnek olarak ₺100M
- Aynı kulüpten maksimum oyuncu sayısı configurable

## Durum
Repository, önceki FOOTBALL IQ analiz prototipinden fantasy football ürününe dönüştürülmektedir.

Çalışma adı: `futbol-iq-fantasy`
